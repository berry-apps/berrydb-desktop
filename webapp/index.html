Zero-jank virtual scrolling

AppKit reuses only visible cell views regardless of whether a result set streams 100 or 100,000 rows into the bounded memory buffer.

01 · Streaming DataGrid & Atomic Edits

Virtual NSTableView with transactional cell writes.

Rows stream incrementally as packets arrive from native wire drivers. Double-clicking any cell with a primary key stages inline mutations and commits all pending changes inside one explicit atomic transaction.

  • ✓ Capped at 1,000 rows by default; expand limit on demand
  • ✓ Server-side WHERE filtering and column-type formatting
  • ✓ Real query cancellation (pg_cancel_backend, KILL QUERY)
02 · Apple Intelligence & Cloud AI SQL Copilot

On-device private inference or cloud reasoning, never guessing writes.

Generate multi-table JOINs, inspect EXPLAIN trees, and render schema ER diagrams directly in a workspace tab. Switch to Apple Intelligence (macOS 26+) for free on-device turns that transmit zero data to external servers.

  • ✓ Safe SELECT auto-runs execute via a separate read-only connection on PostgreSQL, MySQL/MariaDB & SQLite
  • ✓ Mutations trigger explicit user approval cards before execution
  • ✓ Copilot disabled by default on connections labeled Production
03 · Citadel SSH Bastions, Keychain & Schema Designer

Hardware-backed credentials and visual structural audits.

Every password, API key, and passphrase stays inside the macOS Keychain. Pure-Swift Citadel SSH tunnels forward bastion connections inline, while Schema Designer and Visual EXPLAIN expose index health without raw boilerplate.

Architecture FAQ

          

            
              How do MCP live reads prevent destructive writes by coding agents?
              +
            
            

              SQL live reads via berrydb_execute_read_query are off by default. When enabled per connection, each statement must pass BerryDB's read policy and executes inside a database read-only transaction (SQLite: query_only). Production-labeled connections refuse write-capable DB accounts and require explicit time-bound windows (1h, 8h, 24h default, or 7d).
            

          

          

            
              What leaves the Mac when using Apple Intelligence vs Cloud AI?
              +
            
            

              On macOS 26 with Apple Intelligence, on-device turns transmit nothing to BerryDB's AI service. Cloud mode transmits user questions, engine type, table/column schema names, and up to 100 query result rows per tool run. All MCP tool output returned to Claude Code, Codex, or Antigravity flows to that agent's model provider.
            

          

          

            
              How are database credentials and SSH keys stored?
              +
            
            

              Passwords, API tokens, SSH passwords, and SSH key passphrases reside exclusively inside the macOS login Keychain. Private key files remain at their user-managed filesystem paths.
